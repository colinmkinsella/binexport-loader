**For the full readme and source code of the BinExport BinaryNinja Plugin check out [binexport](https://github.com/colinmkinsella/binexport).**<br>
This python script serves as a loader for the plugin since it is written in C++ and might not be directly used with Binary Ninja's plugin manager.<br>

Rikodot's [binja_native_sigscan_loader](https://github.com/rikodot/binja_native_sigscan_loader) project was used as a template for creating this loader.
